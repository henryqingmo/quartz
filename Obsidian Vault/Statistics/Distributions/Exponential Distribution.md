> [!abstract] 
> We need to think about [[Poisson distribution]], which tells us the number of Occurrences before time $t$, suppose we set the number of occurrences to 0, that's equivalent as no arrivals before $t$, and the waiting time $T_1$ greater than t. 
> >[!tip]
> >You can also think of $P(T_1 < t)$ as all the possible waiting time before t, that's corresponds to having the first occurrences at any time slots and don't care about the rest of the occurrences.
> >This has exactly the same outcome as the sum of all possible occurrences before $t$
