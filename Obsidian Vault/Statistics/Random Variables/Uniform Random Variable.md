### Idea
![[Pasted image 20250614185448.png]]
Basically each individual element is an event, and the uniform function maps them to themselves ([[Function Property#Bijection|Bijective]]). 

Hence each of the event has the same probability of $\frac{1}{\text{num of outcomes}}$.
