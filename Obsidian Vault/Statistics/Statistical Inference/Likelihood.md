### Idea
#### Likelihood vs Probability
![[Pasted image 20250808162333.png]]
>[!note]
For probability, we are changing the interval given the distribution, and the probability is the area under the curve.

![[Pasted image 20250808162425.png]]
>[!note]
>Likelihood is the height of the curve given the data points are fixed, we can vary the distribution to get different height for the same data point.
>Which we find by evaluating the data point over the [[Probability Density Function]].

#### Multi-variable
![[Pasted image 20250808164000.png]]
For multiple data points, we treat them as vector of [[Random Sampling]], which we can use a [[Probability Density Function#Joint PDF|Joint PDF]] to model it's likelihood.
