### Idea
#### Inner Join
![[Pasted image 20250627125129.png]]
The Inner Join checks if the primary key equals the customer key, and join them into a row.

#### Left Join
![[Pasted image 20250627125411.png]]
The left join looks through all the rows on the left checks for corresponding right rows, if there isn't, the associated right row will be set to NULL. 
#### Right Join
![[Pasted image 20250627125720.png]]
Exactly the same as the left join.
#### Full Join
![[Pasted image 20250627130038.png]]
Full Join is like Left Join + Right Join, but without the duplicate (Inner Join)

![[Pasted image 20250627130329.png]]
Union basically combine two columns, but with duplicates removed. 
Union All doesn't keeps the duplicates.

Cross Join Just joins two columns side by side.
