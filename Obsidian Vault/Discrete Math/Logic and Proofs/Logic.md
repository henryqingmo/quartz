#### Big Arrow vs Small Arrow
![[Pasted image 20250617124918.png|400]]
For small arrow, we only care about one instance of p implies q. 
![[Pasted image 20250617124931.png]]
For big arrow, we need $p \rightarrow q$ to be a [[Tautology and contradiction|Tautology]] and we can logically derive q from p. 

So to evaluate $P\implies Q$, we need to check these boxes
![[Pasted image 20250617125837.png]]
That means $p \rightarrow q$ is always T, so right hand side always $T$. 

> [!tip]
>But since for all the cases that P if false, $p \rightarrow q$ regardless, we do not need to check those cases, as $q$ doesn't matter and the statement is vacuously true.  

That means we need to prove $p$ true and $q$ true for all cases, for proving implication. This is known as 

Or find a single case for $p$ true and $q$ not true to disprove it.
