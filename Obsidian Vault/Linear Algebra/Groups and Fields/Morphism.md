#### Homomorphism
![[Pasted image 20250607180220.png]]
We basically needs to map each element of $G$ to one element in $H$, such that the structure of the group is preserved. 

![[Pasted image 20250607180954.png]]
Homomorphism doesn't needs to be [[Function Property|Injective or Surjective]].
As shown in this example, there are multiple input maps to the same output.

#### Isomorphism
A bijective mapping of Homomorphism is called Isomorphism
